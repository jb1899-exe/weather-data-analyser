WEATHER-DATA-ANALYSER
- All project code contained within src (source) folder. 
- Modules contains program functionality for main.py.

Modules:
- merging.py (contains logic for merging two datasets)
- pmsort.py (contains parallel merge sort logic)
- searching.py (contains logic for linear and binary search with near-misses)
- sorting.py (contains bubble, insertion, quick, and merge sort logic)
- user_interface.py (contains logic for user interface)

Main:
- main.py (contains logic for main program and ui loop)

Running:
- Run `python -m src.main` from bash terminal.
- Tested on Linux.
